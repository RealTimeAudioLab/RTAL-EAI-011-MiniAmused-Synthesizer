# RTAL MiniAmused v1.2.5 FINAL

Official release based on the user-tested v1.2.5 RC2.

- Resonance bass/body compensation as validated in RC2.
- 180 ms debounce for discrete ON/OFF touch controls, including ARP and HOLD.
- Two full oscillator voices with shared 4-pole ladder filter and ADSR.
- Stereo delay, proven DSP optimization, TURBO9 UI retained.
- Startup splash image and RGB565 header display v1.2.5.
- Serial version strings and Arduino sketch name updated to FINAL.

No additional DSP or sonic changes relative to RC2.

Arduino: Open RTAL_MINIAMUSED_1_2_5_FINAL/RTAL_MINIAMUSED_1_2_5_FINAL.ino.
